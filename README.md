## eNoVA-Nachrichtenmaske

Unter [`enova/`](enova/) liegt eine HTML-Maske, mit der XJustiz-Nachrichten für den elektronischen
Notar-Verwaltungs-Austausch (eNoVA) erfasst, gegen XJustiz 3.6.2 geprüft und als XML oder PDF heruntergeladen
werden können. Zum Starten `enova/index.html` im Browser öffnen; Details in [`enova/README.md`](enova/README.md).
